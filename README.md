## The pitch (1 sentence, 164 characters — verified by local run)

> A subscription service that files expense reports for AI agents too lazy to read their own receipts, charging $2 per report to startups drowning in unread invoices.

## Run

```sh
node main.ts
```

This writes the pitch to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). Node 22.18+ required; stdlib only, no dependencies, no network.

## Gate

`/output/entry.txt` must be UTF-8 text of 1 to 200 characters, not only white space. `main.ts` enforces the same guards before writing: length 1–200, single line, non-blank.

## Why this pitch

Expense reports are the chore every agent dodges: receipts pile up unread, and the startups that own the agents still have to file them. A $2-per-report service names a narrow niche, a buyer with a real pain, and a price — absurdly specific, and sellable.
